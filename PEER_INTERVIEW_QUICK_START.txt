PHASE 3: GOOGLE CALENDAR (30 MINUTES)
==============================================================================

[ ] 1. Create Google Cloud Project
    - Go to console.cloud.google.com
    - Create new project: "PrepHub"

[ ] 2. Enable Google Calendar API
    - In APIs & Services > Library
    - Search "Google Calendar API"
    - Click Enable

[ ] 3. Create Service Account
    - Go to APIs & Services > Credentials
    - Create Credentials > Service Account
    - Fill details and create
    - Click the service account email to open it
    - Go to Keys tab
    - Create new JSON key
    - Download JSON file

[ ] 4. Add credentials to .env.local
    From downloaded JSON file, copy:
    - project_id → GOOGLE_PROJECT_ID
    - private_key_id → GOOGLE_PRIVATE_KEY_ID
    - private_key → GOOGLE_PRIVATE_KEY (include \n literally)
    - client_email → GOOGLE_CLIENT_EMAIL
    - client_x509_cert_url → GOOGLE_CERT_URL

[ ] 5. Share Google Calendar with service account
    - Open your Google Calendar settings
    - Share calendar with service account email
    - Grant "Make changes and manage sharing" permission
    - Save

[ ] 6. Test Calendar API
    - In your application, create a test match and confirm both users
    - Should see calendar event in your Google Calendar
    - Check for Meet link in event

==============================================================================
TROUBLESHOOTING COMMON ISSUES
==============================================================================

ISSUE: "Batch matcher not running"
Solution:
- Check CRON_SECRET is set and correct
- Verify Vercel cron is enabled
- Check vercel.json syntax
- View Vercel Functions logs

ISSUE: "Confirmation emails not sending"
Solution:
- Check RESEND_API_KEY is correct
- Check Resend dashboard for delivery status
- Verify email addresses are valid
- Check spam folder

ISSUE: "Google Calendar events not created"
Solution:
- Verify service account credentials in .env
- Check Google Cloud permissions
- Confirm Calendar API is enabled
- Check error logs for authentication issues

ISSUE: "Users not being matched"
Solution:
- Verify batch matcher is running
- Check requests have exact same role/level/slot
- Ensure both users exist in database
- Check for timezone issues

ISSUE: "Meet links not generating"
Solution:
- Verify Google credentials are correct
- Check conference data version in API call
- Ensure Google Calendar API is enabled
- Check error logs for API failures
