HOW IT WORKS
==============================================================================

Every 10 minutes, Vercel automatically calls: /api/cron/interview-reminders

The cron job:
1. Checks all confirmed interviews
2. Sends early reminder (30 mins before)
3. Sends final reminder (5 mins before)
4. Triggers ready check (10 mins before)
5. Marks no-shows (15 mins after start)

All without needing Upstash or any other service!

Timeline Example:
  T+350 mins: Cron checks... sends 30-min reminder
  T+355 mins: Cron checks... no action (not yet 5 min mark)
  T+360 mins: Cron checks... sends 5-min reminder
  T+370 mins: Cron checks... marks ready check
  T+375 mins: Cron checks... marks no-show if not started

==============================================================================
VERCEL.JSON EXPLANATION
==============================================================================

File: vercel.json

{
  "crons": [
    {
      "path": "/api/cron/interview-reminders",
      "schedule": "*/10 * * * *"
    }
  ]
}

schedule: "*/10 * * * *" means:
  - Every 10 minutes
  - All hours
  - All days

Other useful schedules:
  - "0 * * * *" = Every hour
  - "0 9 * * *" = Daily at 9am
  - "0 0 * * 0" = Weekly on Sunday
  - "*/5 * * * *" = Every 5 minutes

==============================================================================
HOW CRON JOB WORKS
==============================================================================

Request from Vercel:
  POST /api/cron/interview-reminders
  Authorization: Bearer <CRON_SECRET>

Cron job checks:
  1. All confirmed interviews (status = "confirmed")
  2. Upcoming in next 60 minutes
  3. That haven't already sent reminders

For each interview:
  - Calculate minutes until scheduled time
  - If 25-35 mins away: send early reminder
  - If 0-5 mins away: send final reminder + Meet link
  - If 5-15 mins before: mark ready check
  - If 15+ mins past: mark no-show

Sets flags on session:
  - earlyReminderSent
  - finalReminderSent
  - readyCheckStatus.checkedAt
  - status = "no_show"

Returns summary:
  {
    "success": true,
    "updates": {
      "earlyReminders": 5,
      "finalReminders": 3,
      "readyChecks": 2,
      "noShows": 1
    }
  }
